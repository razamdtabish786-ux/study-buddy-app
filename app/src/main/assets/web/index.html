Study Buddy (स्टडी बडी) v1.0

कक्षा 6 से 10 तक के हिंदी माध्यम और द्विभाषी विद्यार्थियों के लिए एक सुलभ, आधुनिक और उपयोगी शैक्षिक वेब ऐप।

मुख्य विशेषताएँ (Key Features):

  • 📖 कक्षा 6-10 के विस्तृत अध्ययन नोट्स (विज्ञान व गणित)
  • 🎯 5-प्रश्नों की इंटरैक्टिव प्रश्नोत्तरी एवं स्कोर ट्रैकिंग
  • 🧮 चरणबद्ध गणित अभ्यास, संकेत और सूत्र
  • 🤖 ऑफ़लाइन स्मार्ट अध्ययन गाइड और परीक्षा रणनीति
  • 💾 प्रोग्रेस ऑटो-सेव (लोकल स्टोरेज)
  • 📱 मोबाइल ब्राउज़र एवं डेस्कटॉप फ्रेंडली रिस्पॉन्सिव डिज़ाइन

वेब ऐप सोर्स फ़ाइलें कैसे डाउनलोड / एक्सपोर्ट करें:

  1. AI Studio मेनू: ऊपर दाईं ओर स्थित सेटिंग्स / डाउनलोड विकल्प से "Export as ZIP" चुनें।
  2. GitHub रिपॉजिटरी: प्रोजेक्ट को सीधे अपने GitHub अकाउंट में पुश करें।
  3. पब्लिक वेबसाइट डिप्लॉयमेंट: डाउनलोड की गई फ़ाइलों को सीधे GitHub Pages, Vercel, Netlify या Firebase Hosting पर अपलोड करें। यह बिना किसी बिल्ड स्टेप के तुरंत लाइव काम करती है!
